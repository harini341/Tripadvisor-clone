# 🌍 TripAdvisor Clone (Responsive Website)

This is a responsive TripAdvisor-inspired website built using **HTML** and **CSS**.  
The project focuses on layout design, responsive behavior, animations, and modern UI styling.

---

## 🚀 Features

- ✅ Responsive Navbar (Desktop & Mobile view)
- ✅ Animated border effect (Plan button)
- ✅ Search bar UI
- ✅ Hero section with image and content
- ✅ Explore cards section
- ✅ Responsive image grid
- ✅ Mobile-friendly footer with accordion style
- ✅ Clean and modern layout

---

## 📱 Responsive Design

The website adapts to different screen sizes:

- 💻 Desktop layout
- 📱 Mobile layout (max-width: 600px)
- Hidden desktop footer replaced with accordion-style footer on mobile

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- CSS Animations
- Font Awesome Icons
- Google Fonts (Gabarito)

---

## 🎨 Special UI Effects

### ✨ Animated Border Effect
The "Plan" button includes a moving light border animation using:

- `::before`
- `linear-gradient`
- `@keyframes`
- `infinite animation loop`
